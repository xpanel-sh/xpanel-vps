# Codigo de conducta

La comunidad de XPanel debe ser respetuosa, inclusiva y colaborativa. No se toleran acoso, discriminacion, ataques personales, publicación de datos privados ni conducta deliberadamente disruptiva.

Los mantenedores pueden editar o retirar contribuciones que incumplan estas normas y restringir temporal o permanentemente la participación. Los incidentes deben reportarse por los canales privados de seguridad o contacto del proyecto.
